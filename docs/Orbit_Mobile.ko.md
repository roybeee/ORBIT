# Orbit 휴대폰 설치와 사용

현재 제공 형태는 홈 화면에 설치하는 웹 앱(PWA)입니다. 설치 후 Orbit 아이콘으로 독립된 앱 창을 열 수 있습니다. 별도 APK 또는 앱스토어 등록은 이번 범위에 포함하지 않습니다.

- 앱: https://orbit-personal-os.hflameb.chatgpt.site
- 설치 안내: https://orbit-personal-os.hflameb.chatgpt.site/install
- 소스: https://github.com/roybeee/ORBIT

## 갤럭시 · Android

1. 위 설치 안내를 **Chrome**에서 엽니다. ChatGPT 안의 브라우저라면 ⋮ 메뉴에서 Chrome으로 열거나 주소를 복사해 Chrome에 붙여 넣습니다.
2. 안내가 나오면 이 앱을 만든 **같은 ChatGPT 계정**으로 로그인합니다.
3. 페이지에 **Orbit 설치하기**가 표시되면 누르고 설치를 확인합니다.
4. 버튼이 없으면 Chrome ⋮ → **설치 및 바로가기 만들기** 또는 **홈 화면에 추가** → **설치**를 선택합니다. 메뉴 이름은 버전에 따라 다릅니다.
5. 홈 화면 또는 앱 목록에 생긴 **Orbit** 아이콘을 눌러 실행합니다.

설치 요청 수락과 실제 설치 완료는 다릅니다. 앱은 `appinstalled` 이벤트 또는 독립 창 실행을 확인할 때만 완료/실행 상태를 표시합니다. 브라우저가 설치 이벤트를 제공하지 않거나 설치를 취소한 경우 메뉴 설치 안내를 계속 사용할 수 있습니다.

## iPhone

Safari에서 설치 안내를 열고 로그인합니다. **공유 → 홈 화면에 추가 → 추가**를 선택합니다. **웹 앱으로 열기**가 표시되면 켭니다. 홈 화면의 Orbit 아이콘으로 실행하고 필요한 경우 같은 계정으로 다시 로그인합니다.

## 첫날 사용 순서

1. 첫 대화 화면의 **연결**에서 AI와 필요한 계정을 설정합니다. 원하는 결과물과 마감일을 이야기하거나 **첫 프로젝트**로 직접 추가합니다. [AI·Plaud·Google 설정 안내](Orbit_Agent.ko.md)를 참고하세요.
2. **새 할 일**을 누르고 소요 시간·프로젝트·마감일을 정합니다. 오늘 집중할 항목을 선택합니다.
3. 일정에서 고정 약속을 등록합니다. 위키와 지식창고에는 회의록·참고 내용을 쌓습니다.
4. 더 보기 → **저녁 회고**에서 오늘의 성과·장애물·에너지를 저장합니다.
5. **내일 제안**을 생성하고 각각 승인하거나 이유와 다음 검토일을 지정해 보류합니다. 승인한 집중 시간은 해당 날짜의 일정에 반영됩니다.

## 저장과 업데이트

- 업무 기록은 로그인한 사용자별 서버에 저장됩니다. 같은 계정의 다른 기기에서 이어 볼 수 있습니다.
- 화면의 **저장됨** 표시를 확인합니다. 연결 중이나 실패 상태는 저장 완료가 아닙니다.
- 네트워크가 끊기면 현재 입력 화면을 유지하고 연결 후 다시 저장합니다. 오프라인 자동 저장·전송 대기열은 없습니다. 화면을 닫거나 새로고침하면 저장하지 않은 입력은 사라질 수 있습니다.
- 앱이 다시 활성화되거나 연결이 복구되면 저장된 기록을 갱신합니다. 작성 중인 폼·회고·문서 또는 결과 미확인 요청이 있으면 덮어쓰지 않고 사용자의 저장/재시도를 기다립니다.
- 새 앱 화면은 완전히 닫고 다시 열면 반영됩니다. 이미 열린 화면은 작성 중인 내용을 보호하기 위해 강제로 새로고침하지 않습니다.
- 설정에서 저장한 기록을 JSON으로 내보낼 수 있습니다. 가져오기 기능은 아직 없습니다.
- AI 대화는 API 키와 계정 연결 후 사용할 수 있습니다. 회고·업무 변경은 승인 카드를 거치고, 실제 시간 배치는 업무 시간·기한·에너지·고정 일정의 규칙을 적용합니다. 자동 저녁 실행·푸시 알림은 아직 제공하지 않습니다.

## 구현 및 검증 경계

로그인이 필요한 manifest에 `crossorigin="use-credentials"`를 지정했습니다. 192/512 아이콘, 512 maskable 아이콘, Apple 180 아이콘 및 범위 내 바로가기를 제공합니다. 키보드의 가시 높이, 화면 안전 여백과 터치 영역을 고려하고 화면 이동을 브라우저 이력에 반영했습니다.

서비스 워커는 허용한 정적 설치 자산만 저장하며 응답 타입과 리디렉션을 확인합니다. 개인 HTML, API, 문서, 내보내기와 인증 경로를 저장하지 않습니다. 최초 설치 전에 연결이 없거나 캐시를 비운 경우에는 정적 오프라인 화면도 사용할 수 없습니다.

자동 검증은 TypeScript, 설치 자산·서비스 워커 동작, 빌드된 서버의 인증/설치 페이지와 기존 저장·문서·계획 로직을 포함합니다. 실제 휴대폰의 설치 UI·터치·키보드 및 플랫폼 로그인을 원격으로 확인한 것은 아닙니다. 최종 설치 확인은 기기에서 사용자가 눌러야 합니다.

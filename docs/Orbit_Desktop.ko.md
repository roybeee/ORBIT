# Orbit · Mac과 Windows에 설치

[Orbit 설치 화면](https://orbit-personal-os.hflameb.chatgpt.site/install)을 컴퓨터의 브라우저에서 열고, 휴대폰에서 사용하던 **같은 ChatGPT 계정**으로 로그인하세요. 기기와 브라우저를 감지해 맞는 안내를 표시합니다. 다른 기기를 선택하거나 브라우저를 직접 바꿔 볼 수 있습니다.

Orbit은 설치형 웹 앱(PWA)입니다. 설치하면 독립된 앱 창으로 실행되고 기존 업무·위키·대화 기록을 이어서 사용합니다. 별도 DMG·EXE 패키지는 제공하지 않습니다.

## Mac

1. Safari에서 설치 화면을 열고 **Mac → Safari**를 선택합니다.
2. **Orbit 열고 설치**를 눌러 에이전트 대화 화면으로 이동합니다.
3. Safari 메뉴 막대의 **파일 → Dock에 추가**를 선택합니다. 공유 메뉴에도 같은 항목이 있습니다.
4. 이름을 **Orbit**으로 확인하고 **추가**를 누릅니다. Dock 또는 Spotlight에서 Orbit을 실행합니다.

Safari 설치는 **macOS Sonoma 14 이상**에서 지원합니다. 메뉴가 없다면 Chrome이나 Microsoft Edge로 같은 앱 주소를 열고 설치 화면에서 해당 브라우저를 선택하세요.

- **Chrome:** 주소창의 설치 아이콘 또는 **⋮ → 전송, 저장 및 공유 → 페이지를 앱으로 설치**.
- **Edge:** 주소창의 설치 아이콘 또는 **… → 앱 → 이 사이트를 앱으로 설치**.

Safari는 현재 페이지를 앱의 시작 주소로 사용할 수 있으므로 **Orbit 열고 설치**로 대화 화면을 연 뒤 설치하세요. [Apple 안내](https://support.apple.com/ko-kr/104996).

## Windows

1. Edge 또는 Chrome에서 설치 화면을 열고 **Windows**를 선택합니다.
2. **Windows에 Orbit 설치하기** 버튼이 보이면 눌러 브라우저의 설치 확인을 완료합니다.
3. 버튼이 없다면 브라우저 선택을 확인하고 **Orbit 열고 설치**를 누릅니다. **Edge … → 앱 → 이 사이트를 앱으로 설치**, 또는 **Chrome ⋮ → 전송, 저장 및 공유 → 페이지를 앱으로 설치**를 사용합니다.
4. 시작 메뉴에서 **Orbit**을 찾습니다. 자주 쓰려면 작업표시줄에 고정하세요.

앱 설치 확인 창은 브라우저가 표시합니다. ‘설치 요청’만 수락한 상태를 완료로 표시하지 않으며, 설치 이벤트나 독립 창 실행을 확인해야 앱에서 완료 상태가 나타납니다. 메뉴 이름은 브라우저 버전에 따라 달라질 수 있습니다. [Edge 안내](https://support.microsoft.com/ko-kr/edge/install-manage-or-uninstall-apps-in-microsoft-edge) · [Chrome 안내](https://support.google.com/chrome/answer/9658361?hl=ko&co=GENIE.Platform%3DDesktop).

## 설치 후 사용

- 아이콘으로 열면 에이전트 대화부터 시작합니다. 기록이 비어 보이면 휴대폰과 같은 계정인지 확인하세요. 설치된 창에서 다시 로그인이 필요할 수 있습니다.
- 일정·프로젝트·위키는 기존 서버에 저장됩니다. 업무 불러오기·저장, 외부 연동과 대화에는 인터넷이 필요합니다. 오프라인 문서 편집은 지원하지 않습니다.
- 창을 완전히 닫고 다시 열면 최신 앱을 불러옵니다. 재설치할 필요는 없습니다.
- 데스크톱 앱 설치와 Hermes 실행 환경 설정은 별개입니다. 대화 화면의 **연결**에서 기존 Hermes 주소를 사용하며, 처음 연결할 때는 [Hermes 설정 안내](Hermes_Setup.ko.md)를 따릅니다.
- 브라우저가 지원하지 않거나 시크릿·앱 내 브라우저에서 설치 메뉴가 없으면 위 지원 브라우저의 일반 창에서 같은 주소를 여세요.

자동 검증 범위는 기기·브라우저 감지, 설치용 manifest·아이콘·서비스 워커, 인증된 설치 경로와 빌드된 서버 동작입니다. 실제 Mac·Windows의 설치 확인 창과 기기 로그인은 사용자의 기기에서 완료해야 합니다.

# Orbit, 나의 페이스메이커 · v0.8

목표에 닿을 때까지 나를 살피고, 먼저 움직이는 AI 비서실장. 일과 건강, 마음과 배움까지, 사용자가 원하는 삶의 궤도를 함께 지킨다.

## 실제 사용 흐름

1. 대화 첫 화면의 **나의 목표** 또는 왼쪽 메뉴에서 목표 대시보드를 연다. 모바일 하단의 **목표**도 같은 화면이다.
2. **목표 관리**에서 원하는 변화와 완료 기준, 기한, 분야를 정한다. 실제 수치가 있으면 시작·현재·목표값과 확인일을 기록한다.
3. **퀘스트 추가**로 직접 실행 단계를 등록하거나 **퀘스트 설계하기**로 Hermes에 설계를 요청한다. 대화 입력란에 목표를 담은 요청이 준비되며 사용자가 보낸다.
4. 제안 카드는 목표, 새 프로젝트, 각 퀘스트의 완료 조건·시간·기한·선행 퀘스트를 보여준다. 승인할 때 하나의 변경으로 저장한다. 기존 업무를 덮어쓰거나 일부만 저장하지 않는다.
5. **실행 경로**의 화살표는 선행 퀘스트에서 후속 퀘스트로 향한다. 노드를 열면 업무를 편집·확인한다. 외부 선행 작업도 점선으로 표시한다. 큰 그래프는 최대 36개 퀘스트와 12개 외부 선행 노드를 표시하고, 전체 업무와 누락된 선행 조건은 아래 목록에서 확인한다.
6. 시작 버튼은 선행 업무, 대기 사유, 보류 날짜, 이미 진행 중인 집중 세션과 상위 목표 상태를 확인한다. 업무 완료가 실제 목표의 수치나 달성 상태를 자동으로 바꾸지 않는다.

## 기록이 쌓이면 달라지는 것

**나를 이해하는 기록**에서 개인 위키·지식·회의록·가져온 메일·저장된 일정·Orbit 대화방을 확인한다. 수치는 현재 저장된 자료의 수이며 외부 계정 전체 보관함 수가 아니다. 계정 연동은 기존 연결 관리에서 설정한다.

- **내가 확인한 기억:** 선호, 고려할 조건, 효과적인 실행 방식, 자기 탐색을 저장한다. 직접 작성하거나 Hermes가 실제 자료를 읽은 후 제안하는 기억 카드를 승인한다. 최대 60개, 기억당 근거 6개다.
- **수정과 삭제:** 변경 즉시 이후 대화와 원페이지 제안의 개인 맥락에 반영한다. 원래의 문서·대화는 보관된다. 이미 생성한 답변과 보고서는 당시 결과이며, 새로운 기억을 반영하려면 다시 요청한다.
- **재확인:** 문서는 확인한 버전에 고정한다. 업무·회고는 확인 당시 내용의 변경 표식을 저장한다. 연결 기록이 바뀌거나 사라지면 관련 기억을 개인화에서 제외하고 재확인을 안내한다.
- **실행 학습:** 최근 30일의 실제 시간을 기록한 완료 건이 5건 이상이면 실제/예상 시간의 중앙값을 표시한다. 계획 보정은 기존 규칙의 0.5~2배 범위 안에서 적용한다. 성격이나 능력을 단정하지 않는다. 미완료 이유는 결과를 기록한 날짜가 있는 건만 최근 패턴으로 집계한다.
- **이전 대화 검색:** 로그인한 사용자의 완료된 Orbit 대화를 검색한다. 사용자 발언과 당시 AI 답변을 구분한다. 최근 12건까지 보이며 원래 대화방으로 돌아갈 수 있다. AI의 추측을 사용자의 사실로 자동 확정하지 않는다.

확인한 기억과 실제 실행 결과를 맥락으로 사용하는 개인화이며, 모델 자체의 가중치를 재학습하는 기능은 아니다.

## 자기 탐색과 외부 AI 대화

**자기 탐색·AI 대화 가져오기**에서 제목과 자료 종류를 선택한 후 텍스트를 붙여 넣거나 `.txt`, `.md`를 읽어 개인 위키에 저장한다. 10만 자, 파일 400KB 이하를 지원한다. 외부 AI 서비스의 전체 대화가 자동 연결되는 기능은 아니다. 기존 이미지·영상·문서 첨부는 대화의 파일 첨부 기능을 사용한다.

사주 해석은 `자기탐색`, `사주` 태그와 해석 자료라는 안내를 함께 저장한다. 이를 근거로 기억을 만들 때도 자기 탐색으로만 보관한다. 목표 성과, 건강 상태, 행동 패턴의 객관적 예측 근거로 사용하지 않는다. 실행 방법에 적용할 선호나 규칙은 사용자가 별도로 확인한다.

## 답변을 신뢰할 수 있도록

Hermes에 전달된 기록에는 서버가 발급한 근거 ID가 붙는다. 새 답변에는 모델이 선택한 유효한 ID만 저장한다. 출처 선택이 없는 답변에는 임의로 조회 자료를 붙이지 않는다. 알려지지 않은 ID를 인용하면 완료 처리하지 않는다.

출처를 누르면 당시 발췌, 날짜, 조회 범위를 확인한다. 문서는 **당시 원문 vN 읽기**로 해당 버전을 읽고, **현재 기록 열기**로 최신 자료를 별도로 연다. 업무·일정은 당시 발췌를 저장하며 전체 변경 이력을 복원하지 않는다. 이전 버전에서 생성한 답변은 출처 제목만 남아 있을 수 있다.

## 주도적 코칭의 범위

기존 ‘나의 궤도’가 목표 페이스·컨디션·업무 대기·회복 시간에 따라 다음 행동을 제안한다. 완료, 잠시 보류, 막힌 이유, 회고를 남기면 다음 판단이 바뀐다. 목표 대시보드와 개인화 기억도 이 실행 흐름을 함께 사용한다.

앱 밖 코칭은 기존 Hermes 예약 실행의 마지막 동기화 스냅샷을 사용한다. 닫힌 Orbit에서 새 메일·일정·회의가 실시간으로 수집되는 기능은 아니다. 상세한 설정과 실행 조건은 [비서실장 사용 안내](Chief_of_Staff.ko.md)를 따른다.

## 유지보수 확인

`npm run test:pacemaker`는 퀘스트 원자적 승인, 목표와 실제 성과 구분, 선행 조건, 상위 목표 보류, 출처 선택, 기억 재확인, 대화 소유권, 실제 저장과 재접속을 검증한다. CI는 기존 에이전트·저장·계획·코칭 검사와 함께 실행한다.

# Orbit 검증 후 보완 개발

## 과거 근거 보존

결정 장부, 운영 지표, 회의 결과, 사업 실험의 원문 링크는 기록된 버전을 요청한다. 과거 버전을 불러오는 동안 최신 본문을 대신 표시하지 않는다. 과거 원문 보기에서는 수정·삭제·이력 복원을 비활성화한다. 회의 결과는 새 결정의 당시 내용과 근거를 별도 보관한다. 이전 회의 기록은 생성 시각과 일치하는 결정 이력이 있을 때만 보충하며, 현재 결정으로 대체하지 않는다.

## 추가한 네 흐름

- 음성: 브라우저가 지원하면 한국어 음성을 최대 60초 인식해 편집 가능한 초안으로 옮긴다. 보내기와 변경 승인은 별도다. 마이크는 명시적 클릭으로 시작하며 화면 전환·비활성화 시 종료한다. 승인 계획·실행 가능한 첫 행동·회의·미결 약속을 바탕으로 아침 원문을 구성하고 최대 60초 읽는다. 브라우저 음성 인식은 제공자 서버에서 처리될 수 있다. 지원하지 않는 환경은 텍스트 입력·원문을 사용한다.
- 사업 실험: 원문 ID와 버전, 프로젝트, 가설, 작은 행동, 기간, 지표·단위·기준값·목표를 저장한다. 하나의 승인으로 실험과 첫 업무를 함께 만든다. 관측값·근거·결론을 기록하면 명시된 목표와 비교한다. 연결 업무의 완료는 별도로 검토한다. Hermes 제안은 해당 버전 원문을 읽은 경우만 허용한다. 최대 100개.
- 사람·거래처: 실제 이름·조직·역할과 프로젝트, 문서, 결정, 위임, 내부 회의를 연결한다. 선택한 관계 및 정확히 일치하는 위임 담당자 이름·별칭으로 맥락을 보여준다. 자동 동명이인 식별은 하지 않는다. 만남 브리핑은 연결된 기록을 Hermes에서 검토할 수 있다. 최대 200개.
- 월간 개선: 서버 실행이 활성화되어 정상 작동하면 지난달 보고서를 한 번 생성한다. 수동 생성도 가능하다. 완료·기한 경과·대기·범위 변경·기록상 사업 전환·새 결정 수·기록한 시간을 집계한다. 실제 업무 앱 사용이나 금전 효과를 추적하지 않는다. 증거가 있는 중단·위임·표준화 제안을 유형별 최대 3개 제시하며 채택·제외와 다음 달 재측정 값·근거를 저장한다. 데이터가 없으면 미측정으로 표시한다. 최근 24개 보고서를 보관한다.

## 실행 이력과 기존 흐름

실행 결과를 변경할 때 업무 제목·사업·기한·당시 예상 시간·실제 시간·미완료 사유·설정을 별도 기록한다. 최근 1,200건을 유지하며 업무가 삭제되어도 기록을 보존한다. 같은 업무·날짜의 정정은 마지막 결과만 집계한다. 이전 데이터는 남아 있는 최신 결과만 보충하고 당시 여유 시간 설정을 추정하지 않는다. 계획 개선 화면은 이 이력으로 완료율과 시간 부족을 계산하고 설정별 표본을 비교한다. 단순 비교를 인과 효과로 표현하지 않는다. 시간 보정 모델 자체는 기존 완료 업무 표본 계산을 유지한다.

위키의 의미 질문은 Hermes로 전달되어 동의어·관련 개념 검색과 실제 원문 읽기를 수행하도록 요청한다. 임베딩 색인을 새로 만든 것은 아니다. 회의의 자연어 분석은 전체 저장 문서 또는 사용자가 제공한 짧은 원문을 읽고 회의 결과 승인 카드로 제안한다. 담당자·기한 등 미확정 사실을 만들어 채우지 않는다. 운영 수치와 위임 회신도 확인한 근거를 승인 카드로 기록할 수 있다. 외부 서비스별 무인 수치·회신 수집기는 아직 별도 개발 대상이다.

네트워크 재연결 시 통신 실패로 대기 중인 워크스페이스 명령을 같은 작업 번호로 재확인한다. 충돌·권한 오류를 자동으로 덮어쓰지 않는다.

## 복원

새 네 기능은 기존 선택 복원에 포함한다. 실험에 필요한 업무·프로젝트·원문과 사람 카드의 연결 기록을 함께 복원한다. 과거 실행 결과만 복원할 때 삭제한 업무를 부활시키지 않는다.

전체 백업 ZIP에서 대화 목록·대화 내용·실행 결과·첨부 원본을 별도 추가 복원할 수 있다. 프로젝트·일정은 먼저 복원해야 연결을 유지할 수 있다. 같은 ID의 기존 기록은 유지한다. 진행 중이던 대화는 실패 기록, 미완료 실행은 취소된 기록으로 보관하며 실행 키·승인·외부 세션을 재개하지 않는다. 복원한 AI 변경 카드를 다시 승인하지 않는다. 부적합한 응답 형식은 거부한다.

신규 ZIP은 각 원본의 SHA-256을 포함한다. 복원 시 로컬 검증값·크기와 서버 수신 스트림을 검증한다. 이전 ZIP은 원본 크기 및 전송 일치 여부만 확인할 수 있다. 사용자 화면은 ZIP 300MB, 각 이력 JSON 10MB까지 지원하며 첨부는 기존 업로드 형식·크기 제한을 따른다. 이미 복원된 기록은 보존하고 중단 후 같은 ZIP으로 재시도할 수 있다.

현재 복원은 전체 환경의 일괄 재설정이 아니다. 인증·외부 연결, 실행 승인 카드, 첨부 미리보기, 조사 도구의 재개 상태, 개인 설정·코칭/사운드 설정을 자동 복원하지 않는다. 이 자료 중 제품 기록은 내보내기 파일에 보관된다. 대용량 ZIP의 분할 복원도 별도 보완 대상이다.

## 검증 범위

회귀 테스트: 과거 원문과 회의 결정 고정, 실험 원자 저장·목표 판정, 날짜별 실행 이력·동일 날짜 정정, 월간 제안 채택/재측정, 사람 연결, 복원 의존성, 계정 분리·중복 방지, 잘못된 응답 거부, 원본 해시·재시도. 화면 렌더링과 과거 원문 로딩 중 최신 본문 미노출도 검증한다.

미리보기 주소는 테스트 브라우저에서 `ERR_BLOCKED_BY_CLIENT`로 차단되어 실제 클릭·모바일 레이아웃 검증은 완료하지 못했다. 실사용 PC의 마이크·ASIDE, 실제 Hermes 응답 품질, 실제 외부 계정 자료 수집은 별도 실환경 검증이 필요하다. 원래 20개 미션 전체의 완전한 운영 검증 완료를 뜻하지 않는다. 대안별 자동 일정 재배치, 외부 서비스별 수치·회신 수집, 전체 설정 복원은 남아 있다.

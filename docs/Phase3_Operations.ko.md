# Orbit 3차 — 대표의 판단 부담 줄이기

## 사업별 시간 배분

프로젝트 목표·마감·대기 조건·기록된 실제 시간을 비교하고 주간 추가 투입 목표와 집중/유지/보류 방향을 검토한다. 금전·인력 예산을 추정하지 않는다. 현재 시각 이후 근무일의 일정·점심·이동·돌봄·가족/회복 보호 구간은 합집합으로 제외하고 버퍼·낮은 컨디션을 반영한다.

시간 배분은 목표이며 캘린더 자동 예약이나 엄격한 사용 한도가 아니다. 승인한 보류는 새 실행 제안과 비서실장 추천에 반영한다. 기존 승인 일정은 취소하지 않는다. 보호 시간은 일정 화면에 표시되며 제안 생성과 승인 충돌 검사를 거친다. 기존 일정과 겹치는 보호 시간은 먼저 조정해야 한다. 적용 해제로 되돌릴 수 있다. 최근 12주 배분을 보관한다.

## 운영 신호

매출·비용·증빙·인사·계약 지표와 확인한 수치를 출처와 함께 기록한다. 외부 시스템 자동 수집은 추가하지 않는다. ODA/ASIDE에서 검토한 수치는 원문 설명 또는 문서 버전으로 연결할 수 있다.

같은 지표의 겹치지 않는 동일 길이 기간 중 최신 기준을 비교한다. 비율과 절대 변화 기준을 함께 적용한다. 0 기준값에서 비율을 만들지 않으며 절대 변화 기준이 있을 때만 판단한다. 미등록·기준 부족·자료 유효 기간 경과·연결 원문 변경은 별도 상태다. 원인 설명은 확인할 가설이며 사실로 단정하지 않는다. 정정은 새 관측으로 저장하고 과거 값과 연결을 보존한다.

사용자가 검토한 후속 행동만 할 일 또는 위임 기록으로 전환한다. 동일 비교의 중복 등록을 막고 해결/제외 근거를 기록한다. 해결 기록은 연결 업무를 자동 완료하거나 메시지를 발송하지 않는다. 지표 60개, 수치 600개, 후속 확인 200개를 보관한다.

## 회의 전후 브리핑

앞뒤 30일의 회의 일정에서 프로젝트를 선택하면 이전 결정, 미완료 위임·업무, 운영 변화, 질문과 관련 문서 요약을 자동 구성한다. 원문을 읽었다고 주장하지 않는다. 저장된 회의록의 원문은 별도로 불러올 수 있다.

회의 후 원문·결과·바뀐 조건·결정·후속 행동을 검토한다. 명시된 `할 일:`/`액션:`/체크박스 문장은 행동 후보로 추출한다. 자연어 전체를 모델로 자동 해석한 결과는 아니다. 승인 시 불변 회의록 버전, 새 결정, 내 업무, 담당자별 위임, 회의 연결 기록을 한 트랜잭션으로 저장한다. 실패나 반복 요청은 일부 반영·중복 생성하지 않는다. 같은 회의 결과는 한 번 확정하며 이후 수정은 연결된 장부/원문에서 한다.

회의 일정의 제목·일시를 보관하므로 외부 캘린더 캐시에서 사라져도 기록을 유지한다. 결과 화면은 당시 기존 결정과 새 결정·바뀐 조건·담당별 후속 상태를 함께 보여 준다. 회의 연결은 100건까지 보관한다.

## 기존 흐름과 데이터 보존

새 기록은 계정별 워크스페이스의 동시 수정 보호를 사용한다. 운영 신호와 주간 배분은 Hermes의 근거·계획 문맥에 포함하며 조회 범위를 제한해 큰 기록으로 요청이 과도해지는 것을 막는다. 추가 메시지 발송·외부 결제·예약 작업은 만들지 않는다.

전체 ZIP 백업 및 선택 복구에 3차 기록을 포함한다. 필요한 프로젝트·문서·수치·업무·위임·결정은 함께 복원하고 연결 관계·정정 이력·기간을 검증한다. 복원한 주간 배분은 비활성으로 두고 다시 검토·승인해야 한다.

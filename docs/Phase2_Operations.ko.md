# Orbit 2차 개발

## 반영 범위

- 개인 위키의 기본 보기를 원문 검색으로 통합. 프로젝트·종류·태그 조건, 본문 발췌, 페이지 이동을 제공한다. 최근 목록 100건의 제목·요약·태그에 대한 프로젝트 분류 제안은 검토 후 적용하며 원문을 유지한다.
- 결정·위임 추적: 프로젝트, 원문 버전, 할 일과 연결한다. 판단 근거·대안·재검토일, 담당자·결과물·기한·확인일을 기록하고 변경 이력을 각각 최대 30회 보존한다. 각 종류 최대 100건. 요청 기록은 발송을 뜻하지 않으며, 결과 수신과 검토 완료는 구분한다. 요청·수락·진행·막힘 상태의 연결 업무는 대기로 바꾸고 확인 날짜를 연결한다. 업무 완료를 자동 처리하지 않는다.
- 열린 결정·위임은 Hermes 대화 및 다음 날 제안의 실제 근거 목록에 포함된다. 확인 날짜가 지난 항목은 추적 화면에서 걸러 볼 수 있다.
- 계획 개선: 최근 30일 보관된 승인 계획 중 해당 날짜의 결과가 남아 있는 항목만 완료율에 사용한다. 미기록은 실패로 계산하지 않는다. 계획기의 프로젝트·인지 유형별 실제 시간 보정 계층과 표본을 공개한다. 결과 기록 시 당시 예상 시간을 보존한다. 시간 부족이 반복되면 버퍼 변경을 제안하고 명시적 선택 시 다음 생성에 적용한다.

## 백업

`/api/backup`은 계정별 제품 기록의 ZIP을 생성한다. 워크스페이스, 문서 과거 버전, 상세 회고, 대화, 승인·실행 이력, 사운드, 캘린더 설정, 수집·운영 설정과 기록 및 R2 첨부 원본·미리보기·조사 원문을 포함한다. 인증 비밀, OAuth 상태, 기기 초안, 실행 재개용 임대는 제외한다. DB는 한 배치에서 캡처하며, 캡처 뒤 파일이 사라졌으면 ZIP을 실패 처리한다. 원문 누락을 성공으로 보고하지 않는다.

ZIP의 `workspace.json`에는 SHA-256 검증값을 포함한다. 파일은 ZIP CRC를 사용한다. 백업 메타데이터 25MB, 전체 아카이브 3GB 이내. 대용량 첨부는 내려받는 속도에 맞춰 스트림으로 전송한다. 브라우저 기본 다운로드를 사용한다.

## 선택 복구

선택한 프로젝트·할 일·문서·목표·규칙·습관·리스크·결정·위임·내부 일정·회고와 필요한 연결 기록을 미리 보여 준다. 같은 ID가 현재 존재하면 기존 기록을 유지한다. 문서의 과거 이력과 회고 상세도 함께 복원한다. 타이머와 계획 자동 재개 상태는 가져오지 않는다. 대화·실행·첨부는 ZIP에 보관되지만 현재 선택 복구 대상은 아니다. 외부 연결은 다시 인증해야 한다.

워크스페이스 수정 버전, 백업 검증값, 기록 형식, 연결 관계, 원문 버전과 회고 상세를 검증한다. 복구는 계정별 원자적 배치로 적용하고 재요청에 중복 생성하지 않는다. 실행 중 작업은 복구를 잠시 차단하며, 쓰기 후 저장된 기록과 원문을 재확인한다. 기존 기록 덮어쓰기, 승인 재생, 외부 작업 실행은 하지 않는다.

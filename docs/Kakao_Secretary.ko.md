# 카카오톡 비서실장

최근 7일 이내의 이미 읽은 대화에서 약속·할 일·미해결 문제를 정리합니다. 결재함의 **카카오톡 비서실장**에서 시작합니다. 실제 업무·일정은 제안을 승인한 뒤 기존 Google 동기화로 반영합니다. 해결책은 제안으로만 남습니다.

## 검토 범위

- 미읽음 메시지가 있는 방과 그 방의 미리보기 본문은 제외합니다.
- 카카오톡에서 입력·전송·반응·첨부 다운로드·링크 열기·설정 변경 기능을 제공하지 않습니다.
- 최초 범위는 최근 7일입니다. 이전 대화를 자동으로 전수조사하지 않습니다.
- 원문 날짜만 확인된 경우 날짜 정밀도를 보존합니다. 시각을 자정으로 채우지 않습니다. 7일 경계의 일부만 해당하는 날짜는 보수적으로 제외합니다.
- 최근 7일에 교신한 방 중 미읽음이 없다고 확인한 방을 자동으로 이동합니다. 목록의 미리보기 본문은 읽지 않고, 진입 직전에 같은 방·배지·위치를 다시 확인합니다. 사용자가 조작하거나 상태가 바뀌면 중단합니다.
- 방에 들어가는 사이나 열린 방에 새 메시지가 오면 카카오톡이 자체적으로 읽음 처리할 수 있습니다. 진입 직전 재확인으로 위험을 줄이지만 이 경쟁을 원자적으로 막는다고 보장하지 않습니다. 미읽음·날짜·방 식별이 불명확하면 해당 방은 건너뜁니다.
- 새 메시지·방 변경·불명확한 읽음 상태·지원하지 않는 화면에서는 수집을 거부합니다. 중단을 이미 발생한 읽음 처리의 취소로 표시하지 않습니다.

## 처음 연결

1. Mac에서 `integrations/orbit-kakao-mac/START-MAC.command`를 실행합니다. 자세한 설치·지원 범위는 같은 폴더의 README를 확인합니다.
2. ORBIT와 연결 프로그램을 같은 Mac에서 열고 **Mac 연결 키**를 입력해 연결 상태를 확인합니다. 연결 키는 현재 검토 창의 메모리에만 유지하며 ORBIT 서버에 전송하지 않습니다.
3. 화면의 **분석 연결 설정**에서 사용 중인 Anthropic/OpenAI API의 모델 ID와 키를 저장합니다. 서버에 기본 OpenAI 연결이 있으면 별도 키가 없어도 됩니다. API 키 저장과 실제 모델 응답 확인은 별개입니다.
4. 카카오톡의 채팅 목록을 열어 두고 **최근 7일 읽은 방 자동 검토**를 누릅니다. 미읽음이 없는 방만 자동 진입하고, 읽음 여부·최근 날짜·원문 구조를 확인하지 못한 방은 건너뜁니다. 직접 연 한 방만 확인하려면 **현재 읽은 방 검토**를 사용합니다.
5. 결과의 근거·확인할 질문·추천안을 검토하고 **결재함에서 검토**로 이동해 반영할 항목을 승인합니다.

화면 기록이나 손쉬운 사용 권한이 필요하면 macOS에서 사용자가 허용해야 합니다. 프로그램은 보안 설정을 자동 변경하지 않습니다. 최소화되거나 지원하지 않는 카카오톡 화면에서는 내용을 추정하지 않습니다.

한 번의 자동 검토는 최대 10방·250메시지·약 2분입니다. 범위·시간·스크롤 지원에 걸리면 부분 검토로 표시합니다. 방이나 메시지가 일부만 수집된 경우 이어가기 해시를 연결 프로그램 메모리에 유지하며 다음 실행에서 남은 항목을 우선합니다. 연결 프로그램을 종료하면 이어가기 상태는 사라지고, ORBIT의 증분 해시가 이미 처리한 근거를 다시 대조합니다. 오래된 고정 방 때문에 목록 검토를 조기 종료하지 않습니다.

## 분석과 저장

원문 발췌·방·발신자·날짜 및 정밀도가 ORBIT에 저장되고, 선택한 분석 서비스로 전달됩니다. 인증번호·비밀번호 등은 수집/검증 경계에서 제외합니다. 모델에는 카카오톡 조작이나 외부 실행 도구가 없습니다. 카카오 전용 분석 대화는 읽기·승인용이며 일반 에이전트 실행 문맥으로 재사용하지 않습니다.

완료한 메시지는 해시로 비교하고 새로운 메시지만 분석합니다. 과거 원문을 다시 모델에 붙이지 않으므로 새 메시지만으로 문맥이 부족하면 질문으로 남습니다. 각 결과의 **이 검토 기록 삭제**에서 확인 후 원문 근거와 미승인 제안을 지울 수 있습니다. 이미 승인된 업무·일정은 유지하고 승인 카드의 근거를 익명화합니다. 자동 보관 만료는 설정하지 않았습니다.

같은 수집 결과와 승인 요청은 재시도해도 중복 등록하지 않습니다. 수집/모델 오류와 Google 등록 상태를 구분합니다. 모델 응답 실패 후 재검토는 같은 조사 ID를 유지하며, 접수 여부가 불분명하면 먼저 결과를 새로고침합니다.

**검토용 수집 파일**은 동일한 구조의 전용 JSON만 받습니다. 일반 카카오톡 전체 내보내기는 지원하지 않습니다. 파일에 적힌 읽음 상태는 라이브 앱 상태의 인증이 아니므로, 사용자가 이미 읽은 범위를 검토해 만든 파일만 사용합니다.

Google에는 참석자·초대가 없는 개인 일정 사본만 전달합니다. 기존 공유 일정이나 참석자가 있는 일정은 이 기능으로 수정하지 않습니다. 대화 전체를 Google 설명에 복제하지 않습니다. 시각·합의·담당자가 불명확하거나 일정이 겹치면 확인 대상으로 남깁니다.

## 개발·검증

API: `GET/POST /api/integrations/kakao`, `GET/POST/DELETE /api/integrations/kakao/model`.
검토 기록 삭제: `DELETE /api/integrations/kakao {id}`. 진행 중 분석·승인이 있으면 거부합니다.
로컬 수집기: `127.0.0.1:43128`, 허용된 ORBIT 출처와 Bearer 키 확인. 일반 임의 명령 인터페이스를 제공하지 않습니다.

관련 회귀는 `tests/kakao*.test.mjs`, `e2e/kakao-review.spec.ts`입니다. Node/SQLite/로컬 브라우저 결과와 실제 Mac·외부 모델·Google 검증 결과를 구분해 기록합니다. `npm run typecheck`, `npm test` 및 별도 Swift 빌드가 필요합니다.

소스 PR 병합, 운영 게시, 실제 수집기 사용 가능 상태는 별개의 단계입니다. 코드 검증 통과를 실제 계정 연동 완료라고 표시하지 않습니다.

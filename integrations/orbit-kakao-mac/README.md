# ORBIT 카카오톡 검토 연결 프로그램

카카오톡에서 **미읽음이 없는 방을 자동으로 열어** 최근 7일 메시지를 ORBIT에 전달하는 macOS 전용 연결 프로그램입니다. 실제 업무·Google 일정 반영은 ORBIT의 검토·승인 흐름에서 이뤄집니다.

현재 모드는 `read_rooms`입니다. 최근 7일 교신한 방을 목록 메타데이터로 선별하고, 진입 직전에 미읽음·방 식별·클릭 대상을 다시 확인합니다. 새 메시지나 사용자 조작이 감지되면 중단합니다. 확인과 진입 사이의 새 도착 경쟁 및 앱 자체 읽음 처리는 원자적으로 막는다고 보장하지 않습니다. 이전 연결 프로그램의 `manual_only` 모드도 ORBIT에서 수동 검토용으로 지원합니다.

## 시작

필요 환경: macOS, Node.js 22 이상, Xcode Command Line Tools의 `swiftc`. 호환성을 확인한 카카오톡 화면 버전은 `26.9.0`입니다. 다른 버전·달라진 화면 구조는 건너뜁니다.

1. 이 폴더를 Mac에 저장하고 터미널에서 `bash START-MAC.command`를 실행합니다. Swift helper를 로컬에서 빌드한 뒤 `127.0.0.1:43128`에만 대기합니다.
2. ORBIT에 로그인하고 카카오톡 검토 패널을 엽니다. 연결 정보 파일 `~/.orbit-kakao/connection.json`의 `token` 값을 연결 키 칸에 입력합니다. 키는 URL에 넣거나 공유하지 마세요. 재시작할 때마다 키가 바뀝니다.
3. 카카오톡의 채팅 목록 창을 최소화하지 않은 상태로 둡니다. 방 이름·읽음 여부·날짜를 구분할 수 없거나 이름이 겹치면 해당 방을 건너뜁니다.
4. ORBIT에서 연결 확인 후 ‘최근 7일 읽은 방 자동 검토’를 실행합니다. 검증된 목록 행의 지원되는 접근성 열기 동작을 사용하며, 필요한 경우 같은 제목 영역의 최신 위치·AX hit-test·실제 포커스가 일치할 때만 내부 계산한 두 번 클릭을 수행합니다. 입력창이나 임의 좌표를 받는 인터페이스는 없습니다. ‘현재 읽은 방 검토’로 한 방만 확인할 수도 있습니다.
5. 결과의 방·날짜·발신자·근거를 검토한 다음 ORBIT에서 반영할 후보를 선택합니다. 구글 연결 실패·일정 충돌은 ORBIT에서 별도로 확인합니다.

손쉬운 사용 권한이 없으면 중단하고 안내합니다. 연결 프로그램이 권한을 자동 요청·부여하거나 설정 화면을 조작하지 않습니다. 권한을 허용하려면 macOS 설정에서 사용자가 직접 판단해 처리해야 합니다. 화면 전체 캡처나 녹화 권한을 요청하지 않습니다.

종료는 연결 프로그램 터미널에서 `Ctrl+C`입니다. ORBIT의 중지는 진행 중인 수집을 폐기하며 이미 승인해 등록된 ORBIT/Google 항목을 되돌리지는 않습니다.

## 읽기 범위

- 목록에서는 방 제목·미읽음 배지 등 직접 표시된 메타데이터만 확인합니다. 마지막 메시지 미리보기의 자식 텍스트는 읽지 않습니다.
- 본문을 읽기 전에 메시지 행의 날짜 메타데이터부터 검사합니다. 최근 7일 밖 행과 날짜 불명 행의 본문은 수집하지 않습니다.
- 날짜만 확인되는 메시지는 `{sentOn: "YYYY-MM-DD", timePrecision: "day"}`로 보냅니다. 자정이나 임의 시각을 발신 시각으로 만들지 않습니다. 7일 시작 경계에 일부만 걸치는 날짜는 전체 제외합니다.
- 발신자를 확인할 수 없는 연속 메시지·시스템 행은 건너뜁니다. 누락이 있을 수 있으므로 수집은 현재 열린 화면의 **부분 검토**입니다.
- 자동 검토는 최대 10방·250메시지·110초·75KB 본문으로 제한하고 목록/본문 스크롤 횟수도 제한합니다. 일부 방 이력을 상한으로 자르면 해당 방을 완료로 처리하지 않고 메시지별 이어가기 해시를 메모리에 유지합니다. 다음 실행에서 남은 메시지를 확인합니다. 스크롤 미지원은 전체 완료가 아닙니다.
- 방·목록 배지·행 식별·사용자 입력 상태를 앞뒤로 대조합니다. 달라지면 수집 결과를 폐기합니다. UI와 카카오 서버를 원자적으로 묶지 못하므로 경쟁 조건을 완전히 없앴다고 보장하지 않습니다.
- 비밀번호·OTP 같은 인증 정보는 출력 전 제외합니다. 대화 전체 DB·내보내기·알림 기록·모바일 백업·숨겨진 창은 읽지 않습니다.

## 제공하지 않는 동작

전송, 메시지 입력, 입력창 초안 삽입, 반응, 파일 다운로드, 링크 열기, 복사/붙여넣기, 전달, 삭제, 검색어 입력, 방 설정 변경, 초대, 키 입력, 일반 좌표 클릭, 임의 셸/AppleScript 실행을 위한 인터페이스가 없습니다. 접근성 동작과 마우스 이벤트는 검증된 읽은 방 제목 열기·지정된 목록/본문 스크롤에만 제한합니다.

카카오톡 데이터는 메모리에서만 처리해 인증된 ORBIT 브라우저에 반환합니다. 로컬 대화·스크린샷 파일과 실행 결과 로그를 만들지 않습니다. 로컬 저장 파일은 연결 키뿐입니다. ORBIT에서의 근거 보관·모델 분석은 별도의 ORBIT 정책과 설정을 따릅니다.

## 로컬 API

기본 허용 출처는 `https://orbit-personal-os.hflameb.chatgpt.site` 한 곳입니다. 모든 실제 요청은 정확한 Host·Origin·Bearer 키가 필요합니다. CORS preflight는 브라우저가 Authorization을 포함하지 않으므로 정확한 Origin·메서드·헤더만 검사합니다.

| 요청 | 역할 |
|---|---|
| `GET /health` | 연결·권한·지원 모드 확인. 대화 본문을 읽지 않음 |
| `POST /scan` `{id: UUID, scope: "current_read_room"}` | 현재 열린 읽은 방의 검토 |
| `POST /scan` `{id: UUID, scope: "recent_read_rooms"}` | 최근 7일 교신한 읽은 방 자동 이동·검토 |
| `POST /stop` `{id: UUID}` | 진행 중/전달 지연된 동일 실행을 취소 |

같은 실행 ID는 재실행하지 않습니다. 응답을 잃으면 저장한 로컬 대화가 없으므로 새 ID로 다시 검토하며, ORBIT의 근거·후보 중복 검사에서 다시 대조합니다. 동시 검토는 1건으로 제한합니다.

## 검증 상태

- Node 정책·HTTP 회귀: 실제 HTTP 서버, 카카오 AX adapter는 mocked.
- Swift helper: 로컬 `swiftc` 빌드 검증.
- 카카오톡 구조: 실제 앱 CUA 관측을 바탕으로 구현. Native helper로 실제 대화를 수집한 실증은 별도 확인이 필요합니다. 정책 테스트 통과를 실앱 수집 성공으로 표시하지 마세요.
- 자동 방 이동은 구현·정책 검사 대상이지만 실제 Native의 방 진입·수집 성공은 실기기 확인 전까지 미검증으로 구분합니다. 모든 방·모든 이력·실제 Google 등록을 검증 완료라고 보고하지 않습니다.

개발 확인 명령:

```sh
bash integrations/orbit-kakao-mac/build.sh
node --test --experimental-test-coverage tests/kakao-mac.test.mjs
```

근거: [Apple Accessibility API](https://developer.apple.com/documentation/applicationservices/axuielement), [AXUIElementCopyAttributeValue](https://developer.apple.com/documentation/applicationservices/axuielementcopyattributevalue(_:_:_:)). 선택한 속성을 조회하는 방식이며, 전체 Accessibility 트리의 텍스트를 덤프하지 않습니다.
